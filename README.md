# course-project
Курсовой проект, написанный на Python по теме "Кластеризация музыкальных треков по характеристикам".

Датасет, который был использован для анализа: https://www.kaggle.com/code/ethan0619/spotify-music-popularity-analysis
Был провелён EDA, распределение признаков, корреляционная матрица, кластеризация 3 методами (k-means, DBSCAN, Hierarchical). 
Проект был выполнен в веб-среде Jupyter Notebook.
